Инструмент сознательно узкий: только страницы `/album/<...>`, только
доступные для прослушивания треки, только mp3-128 (это то, что Bandcamp
отдаёт без авторизации). Если нужен lossless и платный альбом — это
только через покупку, никакой магии нет и не планируется (Возможно).

## Установка

Через [pipx](https://pipx.pypa.io/) - самый чистый способ, не трогает
системный питон:

```bash
pipx install git+https://github.com/W/bandcamp-grabber.git
```

Или если репозиторий уже склонирован локально:

```bash
pipx install ~/projects/bandcamp-grabber
```

Нужен Python 3.10+ и три зависимости, которые подтянутся сами:
`requests`, `beautifulsoup4`, `mutagen`.

## Запуск

```bash
bandcamp-grabber https://artist.bandcamp.com/album/album
```

Скачается в `./downloads/artist/album/` примерно так:

```
downloads/
└── Peaceville/
    └── Isebakke/
        ├── cover.jpg
        ├── 01 - .mp3
        ├── 02 - .mp3
        └── ...
```

По ходу дела выводит примерно следующее:

```
Исполнитель:
Альбом:
Треков:
Папка:

[↓] Обложка:
[↓] 01 -
[↓] 02 -
…
Встраиваю обложку cover.jpg в треки:
  ✓ 01 -
  ✓ 02 -
…
Обложка встроена: .../... файлов.
```

## Флаги

| флаг | что делает | дефолт |
|------|------------|--------------|
| `-o, --output` | папка для сохранения | `downloads` |
| `--no-cover` | не тянуть обложку вообще | — |
| `--no-embed` | скачать обложку, но не вшивать в теги | — |
| `--delay` | пауза между загрузкой треков, секунды | `1.5` |

Полный список — `bandcamp-grabber --help`.

## Как это работает

1. GET запрос на страницу альбома с обычным User-Agent.
2. Ищет `<script data-tralbum="…">` - внутри JSON с метаданными
   и прямыми ссылками на mp3-128 каждого трека.
3. Парсит JSON, забирает `artist`, `title`, `trackinfo[]`, `art_id`.
4. Обложку берёт из `<meta property="og:image">`
5. Качает треки по очереди, кладёт в
   `Artist/Album/NN - Title.mp3`.
6. Открывает `cover.jpg` через `mutagen` и перезаписывает APIC (mp3),
   pictures (flac) или `covr` (m4a) во всех файлах папки.


## Что может сломаться

Bandcamp может менять вёрстку. Симптом - падение
с «`data-tralbum` не найден». Лечится в два шага: открыть страницу
в браузере, посмотреть в DevTools и поправить `parse_tralbum` в `downloader.py`.

Пара моментов, которые стоит держать в голове:

- **Качество.** mp3-128 — единственное, что отдаётся для стрима.
  Lossless - за рамками этого инструмента.
- **Платные альбомы.** Если трек не куплен, в JSON не будет ссылки
  `file.mp3-128`. Скрипт такие треки просто пропустит и скажет об этом.

## Что специально НЕ делается

- Не логинится в аккаунт, не читает куки, не обходит покупку.
- Не поддерживает страницы артистов и лейблов — только `/album/<slug>`.
- Не параллелит загрузку, чтобы не долбить сервер и не получить
  бан по IP. `--delay` крутится именно для этого.
